# Yumeng Chen — Personal Portfolio

**Live site:** https://chenymwork-eng.github.io/

A visual portfolio of AI research, data analytics, technical delivery and commercial consulting.

- Filterable project gallery with contribution and evidence details
- Career and education timeline
- Skills linked to project examples
- Published research and professional contact links

## Maintain the site

- `index.html`: page structure and copy
- `style.css`: visual design and responsive layout
- `app.js`: projects, timeline and interactions

GitHub Pages publishes the `main` branch root. No custom domain or build dependencies are required.
